Prometheus

Prometheus опрашивает адрес /metrics с заголовком Authorization: Bearer <токен>. Готовый стек Prometheus + Grafana с дашбордом — в папке проекта deploy/monitoring.

Как работать с двумя провайдерами

Например, 3 и 1 — три новых соединения из четырёх идут через WAN1. Одно соединение всегда идёт через один канал; устройство, открывающее сайт, обычно остаётся на одном канале — банки и VPN не ломаются. Упал канал — все соединения идут через живой.

Проверка связи

Роутер пингует эти адреса через каждый канал отдельно; канал жив, если ответил хоть один. При падении канала его соединения сбрасываются — клиенты сразу переподключаются через живой. Когда основной возвращается, начатые через запасной загрузки и звонки не рвутся: новые соединения идут через основной.

Подключение

L2TP/IPsec (IKEv1, PSK) — для совместимости с серверами MikroTik, Windows, Cisco. Там, где VPN блокируют, используйте AmneziaWG.

Туннели GRE

Связь «роутер — роутер» поверх AmneziaWG, WireGuard или интернета — как interface Tunnel в Cisco. Серверу AmneziaWG сети за роутерами знать не нужно: он видит только GRE между адресами клиентов (10.8.1.2 ↔ 10.8.1.3), а внутри GRE ходят сети LAN — статическими маршрутами или по OSPF. Работает вместе с любым VPN.

ИмяСостояниеВторой роутерАдрес в GRE Сети за нимТрафик

Новый туннель

Снаружи туннеля

Адреса — в AmneziaWG (у кого какой, видно в приложении Amnezia: список клиентов). «Через интерфейс» awg0 добавит маршрут ко второму роутеру в туннель — нужно в режиме split; в full не помешает.

Внутри туннеля

Туннель добавится в OSPF как point-to-point. Сеть LAN объявите в «Маршрутизация → OSPF» (сеть 192.168.1.0/24, интерфейс br-lan пассивный) — на обоих роутерах.
